# 東海龍珠 Dragon Pearl Pusher

仿湯姆熊「東海龍珠」推珠機台的 3D 網頁遊戲，用 three.js 製作，一個 HTML 檔就能執行。

## 怎麼玩

- 按「投幣」或空白鍵，一枚代幣換一顆珍珠。珍珠會穿過釘板，掉到推盤上。
- 珍珠會掉進下方 7 個獎項口之一：
  - 珍珠口：多掉 2 顆珍珠。
  - 彩票口：得 1 張彩票，有機會點亮派對燈號。
  - 龍珠口：右邊貝殼一定掉出一顆大龍珠（檯面最多 10 顆）。
- 龍珠被推下檯面後滾進轉盤，藍洞 30 張、黃洞 40 張。
- 燈號累積 5 個，進入 15 秒派對時間。這段時間龍珠掉進紅洞，贏得超級大獎 500 張。
- 代幣用完會自動補充。代幣和彩票存在瀏覽器裡。

## 執行

用瀏覽器直接打開 `index.html` 即可，需要網路才能載入 three.js。
